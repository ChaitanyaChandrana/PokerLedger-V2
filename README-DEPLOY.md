# Poker Ledger V2.6.20 — Minimal Setup Forms

Host and join forms now use compact filled fields with smaller sentence-case labels,
no input underlines, and less helper text. The host contact divider is removed;
chip count is a quiet note. The main button has a restrained finish without glow.
All form fields, validation, and submission behavior are retained. Labels are now
associated with their inputs for accessibility.

## Deploy
1. Replace your existing index.html and sw.js with these files.
2. Publish normally, then refresh/reopen the app.
3. Confirm V2.6.20 in the home-screen footer.

Keep all other site files and Firebase settings. JavaScript syntax and local form
checks passed for input availability, accessible labels, chip calculation, and
submission control availability. Browser visual verification was not performed.
Not deployed automatically.
